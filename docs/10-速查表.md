## 10.1 CLI

```bash
claude                              # 互動模式
claude "先看一下 src/api/"           # 帶初始 prompt 啟動
claude -c                           # 續接上一個 session
claude --resume                     # 選一個舊 session 續接
claude -p "prompt"                  # 無頭模式，輸出到 stdout
claude -p "..." --output-format json

claude --model opus                 # 指定模型
claude --agent code-reviewer        # 整個 session 用某個子代理
claude --permission-mode plan       # 指定權限模式
claude --add-dir ../shared          # 加入額外工作目錄
claude --plugin-dir ./my-plugin     # 載入本機 plugin
claude --debug                      # 除錯輸出（hook 匹配、退出碼）
claude --append-system-prompt "..."  # 附加到 system prompt

claude --version
claude update
claude doctor

# MCP
claude mcp add --transport http <name> <url>
claude mcp add --transport stdio <name> -- <command> [args...]
claude mcp add --scope project|user|local ...
claude mcp list
claude mcp reset-project-choices

# Plugin
claude plugin init <name>
claude plugin validate ./my-plugin [--strict]
claude plugin marketplace add <owner/repo>

# 清資料
claude project purge ~/work/my-repo --dry-run
claude project purge ~/work/my-repo
```

## 10.5 Frontmatter 對照

### SKILL.md

```yaml
---
name: my-skill
description: 做什麼 + 何時用（最重要，上限與 when_to_use 合計 1536 字元）
when_to_use: 補充觸發時機
argument-hint: [arg1] [arg2]
arguments: arg1 arg2
disable-model-invocation: true    # 只有你能叫
user-invocable: false             # 只有 Claude 能叫
allowed-tools: Read Grep Bash(git *)
disallowed-tools: WebFetch
model: sonnet
effort: high
context: fork                     # 在子代理裡跑
agent: general-purpose
background: false
hooks: {...}
---
```

### agents/*.md

```yaml
---
name: code-reviewer          # 必填
description: 何時委派給它      # 必填
tools: Read, Glob, Grep
disallowedTools: Write
model: sonnet
permissionMode: default
maxTurns: 20
skills: [api-conventions]
mcpServers: [github]
memory: project
background: true
effort: high
isolation: worktree
color: blue
initialPrompt: "..."
---
```

### rules/*.md

```yaml
---
paths:
  - "src/api/**/*.ts"
  - "src/**/*.{ts,tsx}"
---
```

## 10.6 環境變數

| 變數 | 用途 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 用 API key 認證 |
| `CLAUDE_CODE_SKIP_PROMPT_HISTORY=1` | 不寫逐字稿與歷史 |
| `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` | 關閉 auto memory |
| `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` | `--add-dir` 也載入 CLAUDE.md |
| `CLAUDE_CODE_NEW_INIT=1` | 互動式多階段 `/init` |
| `CLAUDE_CODE_ENABLE_TELEMETRY=1` | 開啟遙測 |

hook 內可用：`${CLAUDE_PROJECT_DIR}`、`${CLAUDE_PLUGIN_ROOT}`、`${CLAUDE_PLUGIN_DATA}`

## 10.7 優先序速查

**CLAUDE.md**（疊加，後讀到的更近）
```
managed → ~/.claude/CLAUDE.md → 根目錄往下每層 → 工作目錄 → 同層的 .local.md
```

**settings.json**（覆蓋，高的贏）
```
managed > CLI 參數 > settings.local.json > settings.json > ~/.claude/settings.json
```
（`permissions` 例外：各層合併，`deny` > `ask` > `allow`）

**Skills**（同名覆蓋）
```
企業 > 個人 ~/.claude/skills/ > 專案 .claude/skills/
```

**Subagents**（方向相反！）
```
managed > --agents > 專案 .claude/agents/ > 個人 ~/.claude/agents/ > 外掛
```

## 10.8 疑難排解對照表

| 症狀 | 先做這個 |
| --- | --- |
| CLAUDE.md 沒生效 | `/context` → 看 Memory files 有沒有它 |
| 設定沒生效 | `/status` 看設定來源 → `/doctor` 看有無無效項 |
| Skill 不會自動觸發 | 加強 `description`，補 `when_to_use` |
| Skill 改了沒反應 | 一般自動重載；外掛的要 `/reload-plugins` |
| Hook 沒跑 | `claude --debug` → 看 matcher 與退出碼；確認腳本有 `+x`；確認目錄已信任 |
| Hook 擋不住 | 阻擋要用退出碼 **2** |
| 子代理不知道背景 | 主對話歷史不會傳過去，要在 prompt 裡寫清楚 |
| MCP 連不上 | `claude mcp list` 看狀態；`/mcp` 走 OAuth |
| 一直跳權限確認 | `/fewer-permission-prompts` |
| 壓縮後忘記事情 | 只有專案根 CLAUDE.md 會重新注入；其他要寫進檔案 |
| context 一直爆 | `/clear`、大任務派子代理、CLAUDE.md 搬去 rules/skills |
| path-scoped rule 沒觸發 | 用 `InstructionsLoaded` hook 記錄實際載入狀況 |
| 想知道 Claude 記了什麼 | `/memory` |
